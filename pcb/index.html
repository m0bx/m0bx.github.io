  1. Open the matching PCB in EasyEDA Pro. Its board origin must match the uploaded Gerbers.
  2. Open Settings → Extension → Script, paste the generated code and run it.
  3. Check the colour silkscreen in EasyEDA preview and in JLCPCB Gerber Viewer before ordering.

Why the extra EasyEDA step? The JLCPCB .FCTS file is an opaque EasyEDA production format. A normal GitHub Pages site cannot create it directly, but EasyEDA’s own API can.
